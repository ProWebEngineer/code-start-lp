# Code Start ランディングページ 要件定義

> 「Code Start」は架空のプログラミングスクールです。

## 1. 目的
- 架空のプログラミングスクール「Code Start」の魅力を短時間で伝え、興味を持った人を次の行動（無料相談）へつなげる。
- Astro と TypeScript で作り、GitHub Pages で無料公開するまでを練習する。

## 2. 見る人
- プログラミング未経験または初心者で、学び始めたいが何から手をつければいいか迷っている人。
- スマホで閲覧する人が多い前提とする。

## 3. 載せる内容

### キャッチコピー
「はじめの一歩を、いちばんやさしく。」

### こんな人におすすめ（3つ）
- プログラミングに興味はあるけれど、何から始めればいいか分からない人
- 独学で挫折した経験がある人
- 自分の手で Web サイトを作ってみたい人

### 学べること（3つ）
- HTML / CSS によるページ作りの基本
- JavaScript で動きのあるページを作る方法
- Git / GitHub を使ったコード管理と公開の流れ

### 受講の流れ（3ステップ）
1. 無料相談で目標と学び方を一緒に決める
2. カリキュラムに沿って、質問しながら学ぶ
3. オリジナルの作品を作って公開する

### よくある質問（2つ）
- **Q. まったくの未経験でも大丈夫ですか？**
  A. はい、基礎の基礎から始めます。
- **Q. どんなパソコンが必要ですか？**
  A. ブラウザが動くパソコンがあれば始められます。

## 4. ページの構成
縦1ページのスクロール型。

1. ヘッダー（ロゴ「Code Start」）
2. ファーストビュー（キャッチコピーと相談ボタン）
3. こんな人におすすめ
4. 学べること
5. 受講の流れ
6. よくある質問
7. 最後の行動ボタン
8. フッター（架空のスクールであることを明記）

### 相談ボタンの動き
- 申し込み機能のないダミーボタンとし、押すとページ内の「よくある質問」セクションへスクロールする。

### デザイン
- 黒を基調に、白い文字と控えめなアクセントカラー1色を使う。
- 余白を広めに取り、プロフェッショナルな雰囲気にする。

## 5. 使う技術
- Astro と TypeScript（セクションごとにコンポーネントを分け、内容データに型を付ける）
- CSS はモバイルファーストで書き、スマホでも読みやすいレスポンシブ対応にする
- GitHub Actions でビルドし、GitHub Pages で無料公開する
- リポジトリ: https://github.com/ProWebEngineer/code-start-lp
- 公開 URL（予定）: https://prowebengineer.github.io/code-start-lp/ （Astro の `base` に `/code-start-lp` を設定）

## 6. やらないこと
- 料金、受講者数、転職実績などの数字は書かない
- 申し込みフォームの送信、決済、ログインなどのサーバー処理は実装しない（ボタンはダミー）
- 複数ページ化、CMS 連携、多言語対応はしない
